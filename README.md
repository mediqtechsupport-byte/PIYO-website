# PIYO Grill & Restaurant — Mobile & Web App

Responsive React + Vite + Tailwind CSS PWA for **PIYO Grill & Restaurant** (Tagaytay City, Cavite), styled in PIYO's signature heritage forest green, warm parchment, and golden-amber aesthetic.

## Features
- **Mobile-First PWA + Desktop Website**: Sticky mobile app bar, bottom navigation bar on mobile, installable web app manifest & service worker (`/sw.js`).
- **Interactive Digital Menu**: Search bar, sticky category pills, dietary/sharing filters, dish detail bottom-sheet/modal with variants and add-ons, and a Table / Takeout Order Tray with SMS & copyable order summary.
- **Heritage & Guest Testimonials**: Showcases Negros heritage favorites (*Bacolod Cansi*, *Chicken Inasal*, *KBL*, *Batchoy*) alongside torn-parchment guest reviews.
- **Visit & Table Reservation Builder**: Live Tagaytay (`Asia/Manila`) open/closed hours status, Google Maps & Waze navigation links, direct contact buttons, and SMS/Email/Messenger inquiry generator.

## Run Locally
```bash
npm install
npm run dev
```

Build and update the live GitHub Pages preview (`https://mediqtechsupport-byte.github.io/PIYO-website/`):
```bash
npm run build
npm run deploy
```
